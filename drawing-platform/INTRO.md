# Introduction

Architecture diagrams are usually either quick but hard to revise, or precise
but slow to create. General whiteboards also make the learner repeatedly draw
the same load balancers, replicas, queues, CPUs, and disks.

System Canvas is for engineers and learners who want a fast spatial notebook
with system-design vocabulary already on the shelf. A diagram remains an open,
versioned JSON document, so it can live beside the system notes it explains.

The application is inspired by the classic Logseq whiteboard experience:
local-first, direct manipulation, an infinite surface, and lightweight visual
thinking. It does not attempt Logseq file compatibility or page/block embeds.
